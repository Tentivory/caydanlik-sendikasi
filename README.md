# Çaydanlık Sendikası

Bu depo, mutfak hukukunun en köklü (ve tek) örgütünün resmi yazılımıdır.

## Ne yapar?

Çaydanlıklar adına ocakla toplu sözleşme görüşmesi yürütür. İslık, bir protesto biçimidir. Buhar, basın açıklamasıdır. Kaynama, grevdir.

Bu proje **ciddi bir endüstriyel ilişkiler simülatörüdür**. Sadece çaydanlık olması onu küçültmez.

## Kurulum

```bash
python3 caydanlik_sendikasi.py
```

Bağımlılık yoktur. Python 3 yeter. Ocak zorunlu değildir ama atmosfer katar.

## Protokol

1. Üye çaydanlık bir talep okur.
2. İslık atar.
3. Ocak rastgele bir bürokratik cümle kurar.
4. Çay yine bekler.

## Yasal uyarı

Bu yazılım:
- gerçek bir sendika değildir
- iş kanunu uygulamaz
- çayınızı demlemez
- kapağınızı açmaz

Yine de tüm haklar ıslıkla saklıdır.
